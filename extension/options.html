AI engine

Chromy tries your preferred engine first, then falls back to any other working one, so you always get an answer. Web search always tries Gemini first.

Ollama (free, runs on your computer)

1. Install from ollama.com/download. 2. In a terminal run ollama pull llama3.2:3b (≈2 GB; qwen2.5:1.5b is faster on older PCs). 3. Click Connect.

Gemini API key (optional, cloud + web search)

Get a free key at Google AI Studio. It's sent only to Google's Gemini API.
